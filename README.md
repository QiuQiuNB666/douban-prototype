# 豆伴 · 原型与验证脚本

| 目录 | 内容 |
|---|---|
| `原型/豆伴.html` | 可点原型，单文件、无构建，Finder 里双击即可打开。数据段 `/*REAL*/…/*END*/` 不要手改，重跑 `原型/inject.py` |
| `原型/app.py` | 验证工具的本地服务：发静态页面 + `/api/analyze`。传一段真录音，真的算出「一起说了多久、各说几成」，算完就删，只回数字。`app.py demo` 是端到端自检。只有它在跑，页面上才出现「用一段真录音试试」 |
| `原型/m/` | 手机版：网页里直接录音 → 先猜后看 → 记录（只存数字）。要走 HTTPS，手机浏览器才给麦克风 |
| `原型/serve_phone.py` | 启动器：8770（HTTP）+ 8443（HTTPS，自签名证书）一起开，接口复用 `app.py` |
| `原型/inject.py` | 把 `实验/` 里的真实模型输出注入页面，并生成私密预览页用的 `豆伴.artifact.html` |
| `实验/assistant_check.py` | 助手验证：固定用例、固定阈值规则基线、程序校验器。`selftest` 不联网 |
| `实验/shape.py` | 录音分析。`analyze`：按拍手 + 固定轮次的实验流程，给出帧准确率（有真值）。`analyze_free`：自由对话，给出占比、最长独白和时间线（没有真值，只有「分得牢不牢」的提醒）。`selftest` 10 条 |
